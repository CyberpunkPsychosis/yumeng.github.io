# 从一个需求，到一个能卖的产品

> 这份文档把「KOL 报价邮件 → 飞书」这个单点需求，往上抽象成一个可复用、可售卖的产品，并挖一挖它背后的潜在需求。给我们自己看，也给以后接类似单时复用。

## 1. 这个需求的本质是什么

客户要的不是"KOL 工具"，而是这条通用流水线的一个实例：

```
非结构化入口  →  AI 抽成结构化  →  人工把关  →  落到某个系统
（邮件/消息/文件）   （任意大模型）    （审核台）     （表格/CRM/DB）
```

四个环节每一个都可以替换，KOL 报价只是把四个槽位填成了
`Gmail / 报价字段 / 运营审核 / 飞书多维表格`。

**把这四个槽位做成可配置，它就从"一个外包活"变成"一个产品"。**

我们已经动手把后两件最值钱的事做了：
- **模型可换**（`llm.js`）：Claude / OpenAI / DeepSeek / 通义 / 智谱 / 混元… 一行 env 切换。
- **字段可配**（`templates/`）：换行业 = 加一个模板文件，引擎不动；审核台字段动态渲染。

## 2. 产品定位

**「AI 数据录入中台」** —— 让杂乱的邮件/消息/文件自动变成干净的表格数据，AI 干活、人只把关。

一句话卖点：**"以前 3 个人抄表，现在 1 个人点确认。"**

为什么"人工确认"是产品的灵魂，而不是麻烦：
- AI 抽取≈95% 准，但客户的数据不容许 5% 错 → 必须有人把关；
- 这一步天然形成"人审过的高质量数据"，反过来能用来持续优化提示词/微调；
- 卖给客户时，"可控、可追溯、不黑箱"正是企业买单的理由。

## 3. 潜在需求（同一个客户，能往深里挖）

把"抄表"做完只是第一层，KOL 营销这条线还能接着卖：

| 层次 | 功能 | 价值 |
|---|---|---|
| 抄表（已做） | 邮件→结构化→飞书 | 省人力 |
| **算账** | AI 按粉丝量/平台估"这个报价贵了还是便宜"，给砍价建议 | 直接省钱 |
| **回信** | 抽完顺手生成一封回复邮件草稿（接受/还价/要资料） | 再省一轮人力 |
| **去重合并** | 同一 KOL 多次来信自动归并，识别同人不同邮箱 | 数据干净 |
| **风控** | 识别虚假粉丝、诈骗话术、异常低价 | 防坑 |
| **履约看板** | 报价→签约→上线→结算 全流程状态流转 | 从录入升级成管理 |
| **复盘分析** | 哪个平台 ROI 高、报价趋势、达人复购 | 决策 |

> 这张表就是给同一个客户做"加购"的路线图——每一行都是一笔新订单。

## 4. 通用产品：换个行业就能再卖一遍

同一套引擎，换个模板，就是一个新行业的产品。这些都是"邮件/消息→录入"的高频刚需：

| 行业模板 | 入口 | 抽取字段 | 落到 |
|---|---|---|---|
| 外贸询盘 | 询盘邮件/站内信 | 客户/国家/产品/数量/预算 | CRM / 飞书 |
| 招聘简历 | 简历邮件+附件 | 姓名/年限/技能/期望薪资 | 人才库 |
| 财务发票 | 发票/账单邮件 | 抬头/金额/税号/到期日 | 财务表 |
| 客服工单 | 客服邮箱/表单 | 类型/紧急度/订单号/诉求 | 工单系统 |
| 合同审阅 | 合同 PDF | 甲乙方/金额/期限/关键条款 | 合同台账 |
| 电商售后 | 退换货邮件 | 订单号/原因/诉求/金额 | ERP |

**对我们的意义**：以后群里来一个"XX 邮件自动整理进 YY 表"的单，
不用从零写——加一个 `templates/xxx.js`、配一下入口和去向就能交付，
甚至直接拿现成产品去卖。

## 5. 可插拔的四个槽位（产品化路线）

| 槽位 | 现在 | 可扩展成 |
|---|---|---|
| 入口 Source | Gmail | Outlook / IMAP / 企业微信 / 钉钉 / WhatsApp / 表单 / Webhook / 文件上传 |
| 抽取 Extract | 模板化 + 任意模型 ✅ | 多模板共存、附件/PDF/图片解析、字段级置信度 |
| 人工 Review | 审核台 ✅ | 批量通过、规则自动放行（高置信度免审）、多人协作/权限 |
| 去向 Sink | 飞书多维表格 | Notion / Airtable / Google Sheets / 数据库 / CRM / 钉钉 / Webhook |

把"去向"也做成插件（像现在的模板和 LLM 一样），产品就完整了。

## 6. 怎么卖

- **按坐席/按量订阅**：基础版（1 模板 1 入口 1 去向）+ 按月坐席费；
- **行业模板市场**：KOL/询盘/简历… 预置模板，开箱即用，加价卖;
- **私有部署**：客户买服务器、数据不出域（正好契合"客户都买服务器"的现状），收一次性实施 + 年维护;
- **模型自带或代付**：客户可填自己的模型 key（省我们成本），也可用我们的（赚差价）。

## 7. 我们现在站在哪

已经具备的产品雏形：**可换模型 + 可配字段 + 人工审核台 + 私有部署**。

**无代码配置后台**已出可点击原型（`admin/index.html`）：客户在页面上选模型、拖字段建模板、
连数据源、配飞书去向、启停运行——全程不碰代码，正是非技术客户能直接用、我们能直接卖的形态。
（原型为纯前端 mock；下一步把它接到真实后端配置存储与各项 API。）

离"开箱即卖"还差：**多入口 / 多去向插件化** + 把原型后台接上真实后端。这两步做完，
它就不再是"我的一个需求"，而是一个可以反复卖的产品。
