# 高端小程序界面 · 编辑式首屏（原生）

还原「Manner」那种杂志感的微信小程序首屏：暖色调、衬线中英标题、沉浸式大图、双语描边底部导航。
**用微信小程序原生 SDK（WXML/WXSS/JS）开发**。

## 两种看法

- **浏览器预览（给客户/你看效果）**：`preview/index.html` —— 纯 H5 高仿，手机框里直接看设计。
  （小程序得在微信里跑，所以做了个浏览器版方便展示。）
- **真·小程序代码**：`miniprogram/` —— 用 **微信开发者工具** 打开本目录即可运行预览。

## 目录

```
miniprogram/
  app.json            全局：navigationStyle=custom（自定义沉浸式导航）
  app.js              读取状态栏/胶囊位置，供自定义导航避让
  app.wxss            暖色调 + 衬线字体兜底
  pages/splash/       首屏：wxml / wxss / js / json
preview/index.html    浏览器高仿预览
```

## 这种「高级感」在原生小程序里怎么做的

- **沉浸式首屏**：`navigationStyle: "custom"`，自己用状态栏高度 + 胶囊位置算出避让区，满屏铺图。
- **衬线中英标题**：小程序不能直接打包中文字体（太大）。做法：① 大标题中文用**切图**或动态加载子集字体；② 英文衬线用 `wx.loadFontFace` 动态加载（见 `splash.js`）。demo 里中文用系统宋体兜底。
- **精准排版**：全程 `rpx` 自适配各种屏宽。
- **双语描边底部导航**：自定义布局（非默认 tabBar），中文在上、英文斜体在下。
- **更顺滑的动效/转场**：生产版可切 **Skyline 渲染引擎**（worklet 动画），手感接近原生 App。

## 换成你的品牌

改 `pages/splash/splash.js` 里的 `data.product`（标题、价格、图片地址）即可；
主题色/排版在 `splash.wxss`。图片建议用品牌方提供的高质量产品图（这种效果很吃素材）。
