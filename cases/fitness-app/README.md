# 轻燃健身 · 跟练 App（Keep 式 · 可配置）

成年向的**健身 App**（参考 Keep），内容完整、四个 Tab：
- **发现**：今日数据、运动分类、为你推荐（横滑）、训练计划、社区精选。
- **课程**：课程库（分类筛选）+ 多日训练计划。
- **社区**：动态信息流（点赞 / 评论 / 分享 / 发打卡），训练完成可一键发到社区。
- **我的**：本周数据、**运动日历打卡**、**勋章成就**、我的收藏。

核心是**全屏跟练播放器**：动作小人动画 + 倒计时进度环 + 语音口令（开始 / 倒数 3-2-1 / 休息）+ 休息预告 +
暂停 / 上一个 / 下一个 → 训练完成自动打卡。做成**通用模板**，换配置就换一套课。

## 怎么玩（浏览器打开 `index.html`）
- 底部切 Tab；首页选课程 / 分类 / 计划 → 课程详情（动作预览、评价、收藏）→ **开始训练**进入跟练。
- 跟练：动作名 + 倒计时圆环 + 要领，动作间自动休息并预告下一个；完成后看时长/动作/千卡并打卡（写入运动日历）。
- 社区可点赞、发动态；我的可看日历打卡与勋章。

## 技术说明
- **动作小人**：SVG 火柴人 + CSS 关键帧动画（开合跳/高抬腿/深蹲/平板/拉伸…），离线、无需视频；正式接真人示范视频即可。
- 语音口令用 `speechSynthesis`，提示音用 WebAudio；计时用状态机；进度环用 SVG。
- 收藏 / 打卡 / 点赞 / 进度都存本地。

## 配置（换课改这个）
`configs.js`：`courses`（课程+动作序列）/ `series`（多日训练计划）/ `categories`（运动分类）/ `feed`（社区）/ `user`（我的数据/日历/勋章）。
`pose` 决定跟练动画。把内容换成你的课程即可复用整套。
