# 轻燃健身 · 跟练 App（Keep 式 · 可配置）

成年向的**健身跟练 App**（参考 Keep）：挑一个训练计划 → 看动作列表 → **全屏跟练播放器**
（动作小人动画 + 倒计时进度环 + 语音口令 + 休息倒计时与下一动作预告）→ 训练完成打卡。
做成**通用模板**，换一份配置就换一套课（健身 / 操课 / 拉伸 / 康复训练 等）。

## 怎么玩（浏览器打开 `index.html`）
- 首页选计划 → 详情看动作与时长 → **开始训练**进入跟练。
- 跟练播放器：动作名 + **倒计时圆环** + 要领提示 + 动作小人动画；倒数 3-2-1 有提示音、动作切换有语音口令。
- 动作之间自动**休息**并预告下一个；可暂停、上一个/下一个。
- 完成后显示时长 / 动作数 / 千卡，并自动打卡（本地记录练了几次）。

## 技术说明
- **动作小人**：SVG 火柴人 + CSS 关键帧动画（开合跳/高抬腿/深蹲/平板/拉伸各一套），离线、无需视频素材。
  正式上线把它换成**真人示范视频**即可（播放器结构不变）。
- **语音口令**：浏览器 `speechSynthesis`；**提示音**：WebAudio 合成。都不依赖外部资源。
- 计时引擎用状态机串起「动作 → 休息 → 下一个」，进度环用 SVG `stroke-dashoffset`。

## 配置（换课改这个）
`configs.js`：
```js
plans:[{ id, title, color, level, target, parts, kcal, equipment, desc,
  actions:[{ name, pose, dur, reps?, rest, tip }] }]
```
`pose` 决定跟练时的小人动画（jumpingjack/highknee/squat/plank/stretch…）。把动作换成你的课程内容即可。
