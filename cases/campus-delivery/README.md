# 宿舍闪购 · 校园即时零售三端（演示 · 可配置）

校园宿舍即时零售/闪送平台，**三端联动**演示，顶部一键切换：**用户端 / 骑手端 / 管理后台**。
按需求把核心商业机制都做成了**可交互、算账正确**的逻辑。

## 用户端 · 利润引擎
- **四级地址锁定**：校区-楼栋-楼层-寝室，结构化选择、不可手填篡改（仅寝室号可填）。
- **凑单宝**（满 3.5 触发）：进度条提示再凑多少解锁下一档。
- **阶梯换购免配送费**：满 4.5 加 1.99 换购饮料、满 8 加 2.99 换购两瓶；**换购即免配送费**。
  换购品平时商城隐藏，仅满额解锁；说明「退款按原价扣差额」防套利。
- **预约单**：次日时段、下单锁库存，前 1 小时免费取消、1 小时内扣 ¥0.5（文案规则）。
- 结算实时算：商品 + 换购 +（免/收）配送费 = 合计。

## 骑手端 · 运力体系
- **排班**：勾选下周可用时段；系统**只向「排班 + GPS 在线」者派单**（关 GPS 或不排班则无单）。
- **佣金明细**：楼层阶梯 1-2 楼 ¥0.7 / 3-4 楼 ¥0.8 / 5-6 楼 ¥0.9，超 5kg +¥0.5，
  **忠诚度补贴**（连续排班满 2 周起 +¥0.1/周，封顶 +¥0.5，中断重置）。
- **送达拍水印照片**：自动给照片加水印（时间 / 地点 / 订单号），用于售后兜底判定。

## 管理后台 · AI 决策
- **多仓/多店隔离**：按楼栋/校区切换，独立统计。
- **每日经营报表**：热销榜 / 滞销榜 / 补货建议 / 毛利率异常提醒，一键**导出 Excel(CSV)**。
- **楼栋战区看板**：各楼栋营业额/单量/客单价 + 状态诊断（热/稳/温/冷）+ 运营建议（推券/换购/拼单满减）一键执行。
- **未触达宿舍**：7 天未下单清单，单间或一键全部**派发 1 元绑定券**。
- **语音库存更新**：标准句式「商品 补/减 数量」+ **二次确认**，防错防恶意改库存。

## 技术说明
- 利润引擎、佣金、忠诚度等数值规则集中在 `configs.js` 的 `rule` / `commission`，便于按客户调参。
- 水印照片用 canvas 现画；导出用 Blob 下载；地图/GPS、真实支付与短信、语音识别接口为正式阶段对接。
