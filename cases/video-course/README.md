# 云课堂 · 视频课平台（网易云课堂式 · 可配置）

电脑网页端**在线视频课平台**（参考网易云课堂/慕课）：课程分类浏览 → 课程详情（大纲/介绍/讲师/评价/购买）→
**学习页**（视频播放器 + 章节目录 + 笔记 + 讨论问答）→ 学完领**结业证书**。换一份配置就换整套课程内容。

## 怎么用（浏览器打开 `index.html`）
- 顶部按**分类**浏览课程；课程卡显示讲师、评分、学习人数、价格、（已报名的）学习进度。
- **课程详情**：你将学到、课程大纲（章节/课时，免费课时可试看、付费需购买）、学员评价、讲师信息。
- 点**免费学习 / 立即购买 / 试看**进入**学习页**：
  - 视频播放器（播放/暂停、进度条可拖动、时间显示）—— 演示用模拟播放（进度自动走 + 标记完成）；
  - 右侧**章节目录**，当前课时高亮、学完打勾、可切换；
  - 下方 **笔记**（在当前时间点记笔记、点笔记可跳转）/ **讨论**（提问，讲师/同学回复）/ 简介。
- 学完全部课时 → **领取结业证书**。进度、报名、笔记都存在本地。

## 技术说明
- **视频播放器**为模拟（占位 + 进度模拟），正式接 `<video>` / HLS / 点播云（阿里云/腾讯云 VOD）即可，播放器外壳与目录/笔记/进度逻辑不变。
- 进度环、笔记打点跳转、章节目录联动均为前端实现，无外部依赖。

## 配置（换课程改这个）
`configs.js`：`courses → chapters → lessons`，课时含 `dur`(分钟) 与 `free`(试看)。课程含讲师、价格、评价、`learn`(你将学到)。
把内容换成你的课程即可复用整套平台。
