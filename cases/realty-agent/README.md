# 经纪人工作台 · 房产中介后台（网页 App · 演示）

房产中介 **B 端经纪人工作台**（参考房客多 / 链家 SE 等），桌面 SaaS 形态，浏览器直接打开即用。
配套 C 端的「找房小程序」（`cases/realty-miniapp`），一套数据两端协同。

## 覆盖功能（你列的需求）
- **工作台**：本月业绩 / 带看 / 成交 / 新增房源 KPI，业绩进度，门店 Top3，来源构成（甜甜圈），待跟进。
- **房源管理**：列表 + **录入房源** / **批量录入**（每行一套）/ **批量分享**（勾选→自动生成群发文案 + 海报）。
- **消息解析自动录入** ⭐：把群里发的自然语言房源消息**粘贴进去，自动拆成结构化房源**（小区/区域/户型/面积/楼层/朝向/价格/标签/电话 + 置信度），勾选一键入库。
- **客源管理**：客源列表 + **录入客源**（需求/预算/等级）。
- **客源跟进**：客户时间线、**添加跟进**、**房客匹配**（按区域/预算/户型自动匹配在售房源）→ 直接发起签约。
- **业绩统计**：经纪人柱状图、团队对比、来源分配统计。
- **业绩榜单**：按 业绩 / 成交单 / 带看 / 新增房源 切换排名。
- **签约发起**：选房源 + 客源 → 成交价/佣金 → 发起电子签约。
- **地图找房**：板块价格气泡聚合，点板块看房源。
- **一对一聊天**：客户会话列表 + 对话。

## 消息解析（重点）
`parse.js` 用正则 + 关键词启发式，从一段自然语言里抽取字段并给**置信度**：
```
【徐汇·急售】建岚公寓 2室1厅 71平 中楼层 朝南 698万 满五唯一 近地铁 13800001111
→ { 小区:建岚公寓, 区域:徐汇, 户型:2室1厅, 面积:71, 楼层:中楼层, 朝向:朝南, 价格:698万, 标签:[满五唯一,近地铁], 电话:138****1111, 置信度:高 }
```
每行一套，支持多套批量；正式可换成更强的 NLP / 大模型抽取（接口不变）。
