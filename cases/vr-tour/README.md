# VR 实景样板间 · 720° 看房（H5 可玩 · 可配置）

房产「720° 全景看房」小程序：进楼盘 → 选户型/区域 → 切场景（大门 / 电梯厅 / 儿童区 / 客厅…）→
**按住拖动环视一圈**，全景里点**门口热点**走进下一个房间。对齐参考的 VR 看房小程序交互。

打开 `index.html` 直接能玩，手机触摸拖动、桌面鼠标拖动 + 滚轮缩放，双指捏合缩放。

## 怎么玩
- **拖动**屏幕环视 360°，**滚轮 / 双指**缩放。
- 全景里的**白色光点**是门口热点，点一下走进对应房间（大门↔单元门↔电梯厅↔儿童区↔中庭…）。
- 底部：切**楼盘**（换色调氛围）、切**户型/区域**、点**缩略图**直接跳场景；左下「场景切换」可收起面板。

## 技术要点
- **极简自研 WebGL 全景**（`viewer.js`，无第三方库）：equirectangular 贴到球面，相机在球心，
  透视投影 + lookAt 矩阵，拖动改偏航/俯仰，带惯性与静止自动旋转。
- **热点对齐**：门口在全景图里按 `yaw` 画成拱形门洞；热点标记用同一套 MVP 投影到屏幕，**与门洞精确重合**，点击切场景。
- **演示用全景为手续生成**（`pano.js`）：把天花/墙/地/采光/门洞画进一张 2048×1024 equirectangular 图，
  不依赖外部素材，保证离线可玩。**正式上线把它换成客户实拍的 720° 全景图即可**，viewer 不用改。
- **设备适配**：`devicePixelRatio` 高清、竖屏画布、指针事件统一鼠标/触摸。

## 配置（换楼盘 / 换场景改这个）
`configs.js`：
```js
{
  title, agent,
  projects:[{ id, name, tint }],            // 楼盘：tint=该盘色调
  groups:[{ id, name, scenes:[             // 区域/户型
    { id, name, feature, palette,          // 场景：配色
      hotspots:[{ to, yaw, label }] }      // 门口热点：去哪个场景、方向、文字
  ]}]
}
```
换真实楼盘：把每个 `scene` 的「手续生成全景」换成实拍 720° 图（viewer 用同样的球面贴图），配上 `hotspots` 即可。

## 两种看法
- **浏览器可玩**：`index.html`（本目录）。
- **原生小程序**：`miniprogram/` —— 用**微信开发者工具**打开。首页是房产中介门户宫格（参考截图），
  点「实景样板间」用 **`web-view` 载入本 H5 全景**（需在小程序后台配置「业务域名」）。
  也可纯原生渲染：把 `viewer.js` 的着色器与矩阵搬到 `<canvas type="webgl">`，逻辑一致。
