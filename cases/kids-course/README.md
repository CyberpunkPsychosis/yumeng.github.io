# 小步课堂 · 儿童互动课程平台（电脑网页 + 单机 App · 接 AI）

给 5 岁左右小朋友的**互动数学课**，做成**通用课程平台**（像 Keep 的课程列表 → 闯关式上课）：
课程 → 单元 → 课时，逐题互动（数一数 / 比多少 / 加减法 / 选一选），**做错有 AI 小老师讲解**。
换一份配置即可变成拼音、英语、亲子运动等其它课程。

## 怎么玩（浏览器直接打开 `index.html`）
- 首页选课程 → 进单元/课时 → 一题一题闯关，**答对有音效 + 星星**，答错温柔提示重做。
- 每题可**点喇叭语音读题**（适合还不识字的小朋友）；完成一课有奖励页和星级。
- 进度自动保存在本地。

## 准确 + AI：关键架构
- **数学对错一律本地代码判定**（`grade()`），确定性、绝不算错。
- **AI 小老师只负责讲解 / 鼓励 / 出相似题**，不参与判分 —— 这样既有“像千问那样”的互动讲解，又保证“准确”。
- 点首页右上角接入大模型：内置**通义千问 (Qwen, DashScope OpenAI 兼容)** 与通用 OpenAI 兼容预设，填 Key 即用；
  **不填也能玩**（离线小老师按题型给规则化提示）。`ai.js` 是对接层，换模型只改配置。

> 注意：浏览器直接填 Key 会暴露在前端，仅适合自己单机用；正式上线建议用后端中转。

## 单机桌面 App
同一套网页可用 **Electron** 打包成 Windows/Mac 单机程序，无需浏览器、可离线：
```
cd desktop && npm i && npm start      # 窗口运行
npm run dist                          # 打包安装包(electron-builder)
```
（也可用 Tauri 打包，体积更小，思路一致。）

## 配置（换课程改这个）
`configs.js`：课程 → 单元 → 课时 → 步骤。步骤类型：`teach`(讲解) / `count`(数数) / `compare`(比多少) / `choose`(选一选)；
算术课时用 `gen:{type:"add|sub",max,n}` 让引擎自动出题。把内容换成别的学科即可复用整套互动/语音/AI 框架。

## 目录
```
index.html  app.css  app.js（单页：课程/单元/上课/奖励/设置）
configs.js（课程内容）  ai.js（千问/OpenAI 兼容对接 + 离线兜底）  icons.js
desktop/（Electron 单机封装：main.js + package.json）
```
