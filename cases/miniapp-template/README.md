# 可配置高端小程序模板（原生）

一套内置「高级感」排版/动效的微信小程序模板。**布局固定、内容配置化**：
以后来个新客户（摄影工作室、咖啡品牌、品牌官网…），你只要**换一份配置 + 传素材**，
就能生成一套排版照样高端的小程序。

## 怎么用（你以后主要的工作）

1. 复制一份配置，按区块填文字、换图片地址、选主题色。
   - 浏览器预览改 `configs.js`；原生小程序改 `miniprogram/config.js`（同一套结构）。
2. 图片用客户提供的高质量素材（这种效果很吃图）。
3. 完事。布局、动效、字体、响应式都是模板内置的，不用碰。

## 配置结构

```js
{
  theme: { mode: "dark|cream|light", accent: "#c8a15a" },  // 主题与强调色
  brand: "品牌名",
  blocks: [            // 按顺序拼区块，想要哪些放哪些
    { type:"cover",   ... },  // 沉浸式首屏（大图/标题/副标，可带价签、底部双语导航）
    { type:"gallery", ... },  // 图墙（cols:2|3）
    { type:"services",... },  // 套系/菜单（名称+说明+价格）
    { type:"split",   ... },  // 图文（关于/特色）
    { type:"contact", ... },  // 预约/联系（任意键值行）
  ]
}
```

## 两种看法

- **浏览器预览**：`preview/index.html` —— 顶部可切「摄影工作室 / 咖啡品牌」，**同一模板、两份配置、两个行业**，证明换素材即换行业。
- **真·原生小程序**：用 **微信开发者工具** 打开本目录 → `miniprogram/` 运行；`config.js` 当前是摄影工作室那份。

## 内置的「高级感」从哪来

- 自定义沉浸导航（`navigationStyle: custom`）、`rpx` 全适配。
- 衬线中英标题：英文用 `wx.loadFontFace` 动态加载；中文大标题生产环境建议切图或加载子集字体。
- 暗调/暖色/简约三套主题，一个 `mode` 切换；强调色 `accent` 一处改全站。
- 滚动进场动画；图墙/列表/图文/联系等区块自由拼装。
- 想要更顺滑可上 Skyline 渲染引擎。

## 加新区块类型？

预览端在 `preview/preview.js` 的 `BLOCKS` 里加一个渲染函数；原生端在 `home.wxml` 加一个
`<template name="...">` 即可。模板是开放可扩展的。
