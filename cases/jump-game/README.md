# 跳一跳 · H5 小游戏（浏览器可玩）

微信经典「跳一跳」的网页复刻：**长按蓄力 → 松开起跳 → 等距落点判定 → 计分 + 相机跟随**。
纯 `<canvas>` + `requestAnimationFrame`，打开 `index.html` 直接能玩，手机触摸、桌面鼠标/空格都行。

## 玩法
- 长按屏幕（或按住空格）蓄力，蓄力条越长跳得越远；松开起跳。
- 跳到下一个方块上 → 计分 +1；落点越居中越「完美」，连续完美连击加分递增（2/4/6…）。
- 跳过头或不够 → 坠落，游戏结束，记录最高分（存在本地）。

## 技术要点
- **等距 2.5D 渲染**：方块画成等距立方体（顶面菱形 + 左右侧面三段条纹还原质感），按屏幕纵深用画家算法排序绘制；`devicePixelRatio` 高清适配。
- **蓄力物理**：按下记时长 → 映射跳跃距离；跳跃走「当前→下一块」单位方向 + 抛物线高度 + 翻转 + squash&stretch 回弹。
- **落点判定（沿跳跃轴 1D）**：`gap−r ≤ d ≤ gap+r` 判成功，`|d−gap| ≤ r·0.24` 判完美居中。
- **相机跟随**：成功后把当前块缓动平移回固定锚点，世界整体位移，前方再生成新方块。
- **状态机**：start → idle → charging → jumping →（recenter | falling）→ over。

## 移植到微信小游戏
canvas 绘制与游戏循环逻辑与平台无关：把 `getContext`、`requestAnimationFrame`、指针事件换成
微信小游戏的 `wx.createCanvas` / `canvas.getContext` / `wx.onTouchStart|End`，主体逻辑可直接复用。
