# 代扔垃圾 / 上门清运小程序（五享扔式）

上门代扔生活垃圾 / 大件家具清运的微信小程序原型。**配置驱动**：换品牌、换品类、换价格只改一份 `configs.js`，下单逻辑与界面不动。内置两套示例场景：

- `trash` —— 生活垃圾代扔（绿色主题，参考「五享扔」）
- `clean` —— 大件家具 / 装修垃圾清运（橙色主题）

## 在线预览（可点）

- 生活垃圾代扔：`preview/index.html?c=trash`
- 大件 / 装修清运：`preview/index.html?c=clean`

浏览器里就能交互（手机壳预览）。真机即微信小程序。

## 能真的点的完整闭环

1. **首页** —— 实时动态滚动、服务入口（单次代扔 / 包月套餐）、大件品类、超值券包、服务流程、客服浮标、底部 Tab。
2. **单次代扔** —— 选垃圾类型 → 选袋数 → 选取件楼层 + 有无电梯 → 选上门时段 → 填地址 → 可勾选「代扔券」抵扣，**价格实时计算**。
3. **微信手机号登录** —— 下单 / 买套餐 / 领券前弹出微信一键登录（演示为模拟登录浮层；原生用 `<button open-type="getPhoneNumber">`）。
4. **大件代扔** —— 多品类多数量选择，叠加无电梯搬运加价，按件估价后下单。
5. **包月套餐** —— 每日 / 隔日 / 每周套餐对比，开通。
6. **超值券包** —— 单次代扔券券包（买得多省得多），购买后券数入账，下单自动抵扣。
7. **订单** —— 待接单 / 服务中 / 已完成状态，待接单可取消。
8. **我的** —— 券数 / 套餐 / 订单概览，常用工具入口。

## 计价引擎（在 `configs.js` 的 `rule` 里，精确可核对）

**单次代扔**：`总价 = 起步价 + (袋数 − 起送袋数) × 每袋加价 + 加急费(立即上门) + 无电梯搬运((楼层−1) × 每层加价)`，再减去代扔券抵扣（每张抵 `couponFace`）。

> 例（trash）：厨余 ×3 袋、无电梯 6 层、立即上门 = `5 + 2×3 + 3 + 5×1 = ¥19`。

**大件代扔**：`总价 = Σ(单件价 × 数量) + 无电梯搬运((楼层−1) × bulkyNoElevatorPerFloor)`。

## 配置怎么改

`configs.js` 每套场景包含：

| 字段 | 含义 |
|---|---|
| `brand` / `city` / `theme.accent` | 品牌名 / 城市 / 主题色 |
| `hero` / `feed` / `steps` | 首页大图文案 / 实时动态 / 服务流程 |
| `trashTypes` | 单次代扔可选的垃圾类型 |
| `bulky` | 大件品类与单价 |
| `plans` | 包月套餐与价格 |
| `couponPacks` / `couponFace` | 券包档位 / 每张券面额 |
| `rule` | 计价规则（起步价、加价、加急、楼层） |
| `slots` / `orders` | 预约时段 / 演示订单 |

加一个新城市 / 新品牌：在 `JUNK_CONFIGS` 里复制一套改值即可，前端零改动。

## H5 预览 → 微信原生映射

| 预览实现 | 微信小程序原生 |
|---|---|
| `VIEWS` + `go(view)` 单页路由 | 多 `page` + `wx.navigateTo` / `wx.reLaunch` |
| 模拟登录浮层 | `<button open-type="getPhoneNumber">` 拿手机号 |
| `data-act` 事件委托 | `bindtap` + `data-*` |
| `localStorage` 可加（演示态在内存） | `wx.setStorageSync` 持久化券 / 套餐 |
| 内联 SVG 图标 | CSS `mask` + data-URI SVG（`background-color` 上色） |
