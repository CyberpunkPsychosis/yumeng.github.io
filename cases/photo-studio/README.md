# 视觉系作品集小程序（摄影工作室 · 杂志风）

参照客户提供的 SANJING 叁景视觉设计稿（203 页 PDF）与 Dribbble 杂志类概念稿（Bookshelf / Mogaz）复刻的**视觉系作品集小程序**原型。**配置驱动**：换工作室 = 只改 `configs.js`（品牌 / 风格类别 / 作品 / 文案 / 联系方式），页面与动效不动。内置两套示例：

- `sanjing` —— 人像摄影 · 暗调编辑部风（对照设计稿）
- `wedding` —— 婚纱旅拍 · 亮调（证明一份配置换一家店）

## 在线预览（可点）

- 暗调人像：`preview/index.html?c=sanjing`
- 亮调婚纱：`preview/index.html?c=wedding`

## 能真的点的闭环

1. **首页** —— 品牌字标 + 搜索 + **作品卡堆（可拖拽左右滑切换、带惯性旋转）**，点卡进详情；白色浮岛式图标 Tabbar（作品 / 类别 / 我的）。
2. **杂志式作品详情** —— 全屏系列色背景、编号衬线大字（Fs-01）、英文刊眉、长图文成组展示、**点赞（需微信登录）/ 分享**、文末「联系工作室」CTA。
3. **風格類別** —— 封面网格 → 系列页**横滑大卡（scroll-snap）**+ 点赞数据胶囊 → 详情。
4. **我的** —— 微信一键登录（模拟）、喜爱（收藏聚合）、写真集网格、视频/设置占位。
5. **工作室名片** —— 简介 + 地址 + 地图示意 + **电话 / 官方微信二维码弹窗**；作品详情底部资讯 ActionSheet（加微信 / 电话 / 取消）同款。
6. **扫码页** —— 四角取景框 + 扫描线动画（云相册入口示意）。

## 关于占位图（重要）

示意海报由代码**按每个作品的色调自动生成**（SVG：主色渐变 + 光斑 + 细框 + 编号衬线字 + 品牌字标），用于演示构图与色调氛围。**交付时替换为工作室真实成片**：每个作品的 `paras` 与封面换成图片 URL 即可，需配合压缩 / 懒加载 / CDN（满屏大图小程序的性能关键）。

## 配置结构（`configs.js`）

| 字段 | 含义 |
|---|---|
| `brand` / `logo` / `theme` | 品牌名 / 字标 / 主题色与明暗模式（dark/light） |
| `studio` | 工作室名片：简介 / 地址 / 电话 / 微信号 |
| `cats` | 风格类别（含点赞/浏览数据） |
| `works` | 作品：编号、标题、中英文案、色调（c1/c2/ink）、图文段落 |

## H5 预览 → 微信原生映射

| 预览实现 | 微信小程序原生 |
|---|---|
| 卡堆 pointer 拖拽 | `swiper` 层叠自定义 / `wx.createAnimation` + touch 事件 |
| scroll-snap 横滑 | `swiper` `previous-margin/next-margin` |
| 模拟微信登录 | `<button open-type="getPhoneNumber">` |
| SVG 占位海报 | 真实成片图片 + CDN + 懒加载（`lazy-load`） |
| 二维码弹窗 / ActionSheet | 原生组件 + `wx.previewImage` 长按识别 |

## 不在本轮（选定后成品阶段补）

云相册真实对接（扫码看片/选片）、在线预约档期与订金支付、客片交付系统、视频栏目。本预览聚焦设计稿的视觉还原与浏览-收藏-联系闭环。
