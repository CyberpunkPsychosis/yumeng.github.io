# 找房小程序 · 地图/地铁找房（C 端 · 可玩 · 可配置）

房产中介 C 端找房小程序（参考贝壳/链家），**换城市/换业务只改配置**。已能真的点：
搜索找房 → **地图找房**（价格气泡聚合）/ **地铁找房**（线路图选站）→ 房源详情 →
**预约看房**（微信手机号登录）/ **在线咨询**（IM）/ **在线签约 + 微信支付**（演示）；**收藏 + 浏览记录**。

内置 2 个业务：**二手房 / 租房**（切换顶部按钮，主题色与价格单位随之变）。

## 怎么玩
- 首页四个入口：地图找房 / 地铁找房 / 预约看房 / 我的收藏。
- **地图找房**：示意地图上每个板块一个**价格气泡**（均价·套数），点气泡只看该板块房源。
- **地铁找房**：示意地铁线路图，点**站点**看该站附近房源。
- 房源卡可**收藏**（心形）；进过的房源进**浏览记录**；详情可**预约看房 / 在线咨询 / 在线签约**。
- 「我的」里看收藏 / 浏览 / 预约 / 合同。

## 技术说明（地图）
演示用的是**示意地图 / 地铁图**（SVG + 价格气泡 / 折线站点），离线可玩、不依赖密钥。
**正式上线接高德 / 百度地图 SDK** 换成真实地图与 POI 即可——其余交互（气泡聚合、点站找房）逻辑不变。

## 配置（换城市/业务改这个）
`configs.js`：
```js
{
  theme:{accent}, brand, city, mode:"二手房|租房", priceUnit,
  filters:{ regions:[], prices:[], rooms:[] },
  districts:[{ name, mx, my }],          // 地图气泡位置(%)，均价由房源算
  subway:{ lines:[{ name, color, stations:[] }] },
  listings:[{ id, region, district, subwayStations:[], mx, my,
    title, community, cover, images:[], price, unitPrice,
    rooms, area, floor, orient, year, tags:[], features:[], desc,
    agent:{ name, badge, rating, sales } }],
}
```
